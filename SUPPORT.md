# Support

Open an issue at [`.../issues/new/choose`](https://github.com/heyhi-design/photo-to-print/issues/new/choose):

- **Something's broken?** Pick "Bug report." Include the output of `python3 scripts/kit.py doctor`.
- **A print came back wrong in a way the checks didn't catch?** That's the most useful report you can send. Say what was wrong, what the review sheet showed, and which question would have caught it.
- **Not sure if it's a bug or a "how do I"?** Open an issue anyway.

Expect a first response within 5 business days. For anything you'd rather not post publicly: hello@heyhi.design
